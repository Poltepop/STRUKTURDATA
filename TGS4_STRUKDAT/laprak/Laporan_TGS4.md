Program ini adalah sebuah sistem manajemen "ATYA CHART RECORD" berbasis Command Line Interface (CLI) menggunakan bahasa C. Program ini dirancang untuk menyimpan, menampilkan, mengubah, menghapus, serta mencari data Chart (yang berisi ID, Nama, dan Tingkat Kesulitan). Dalam pengembangannya, program ini menerapkan konsep *Dynamic Memory Allocation* (Alokasi Memori Dinamis) di mana ukuran array ditentukan oleh pengguna pada awal program. Struktur datanya didefinisikan melalui `struct` bernama `Chart`. Pemanfaatan **pointer** sangat krusial dalam program ini; variabel `chart` di fungsi utama dideklarasikan sebagai pointer (`Chart *chart`) yang menyimpan alamat awal dari blok memori yang dialokasikan oleh fungsi `malloc()`. Pointer ini kemudian diteruskan (di-passing) ke berbagai fungsi sehingga setiap modifikasi data akan langsung mengubah nilai pada memori asli. Akses elemen pada array dinamis ini secara konsisten menggunakan aritmatika pointer `(C + i)->` alih-alih menggunakan indeks array konvensional.

Menu pertama "Tambahkan chart" berfungsi untuk memasukkan data chart baru ke dalam sistem. Program akan meminta pengguna memasukkan ID, nama, dan tingkat kesulitan chart. Pada proses ini, program memvalidasi ketersediaan ruang dengan `isFull()`, lalu melakukan iterasi. Penggunaan **pointer** terlihat saat program melakukan penelusuran slot kosong dengan mengevaluasi kondisi `(C + i)->idChart == -1`. Setelah slot kosong ditemukan, program akan mengakses alamat memori spesifik `(C + i)` tersebut dan memodifikasi datanya melalui fungsi `createData()`. Error handling yang diterapkan meliputi validasi nilai ID chart (tidak boleh bernilai negatif) dan validasi array penuh, di mana penambahan data dibatalkan jika `isFull()` mengembalikan nilai benar.

Menu kedua "Tampilkan Semua Chart" digunakan untuk mencetak seluruh data chart yang telah tersimpan. Program menelusuri memori secara berurutan mulai dari awal hingga batas maksimal alokasi. Keterkaitannya dengan **pointer** adalah digunakannya aritmatika pointer `(C + i)` untuk berpindah dari satu blok data struktur `Chart` ke blok berikutnya dalam memori. Jika suatu slot terdeteksi memiliki data valid (`idChart != -1`), nilai pointer pada indeks tersebut akan di-dereference untuk mencetak `idChart`, `nameChart`, dan `difficultyChart`. 

Menu ketiga "Edit Chart" memberikan fungsi untuk memperbarui data chart yang sudah ada di memori. Pengguna memasukkan ID chart yang ingin diubah. Program menggunakan fungsi `getIndex()` yang memanfaatkan perulangan **pointer** untuk mencocokkan ID dan mengembalikan posisi indeksnya (offset). Setelah posisi tersebut ditemukan, program langsung menimpa data pada alamat memori `(C + index)` dengan input yang baru. Pointer memungkinkan program untuk melakukan mutasi data secara in-place di lokasi memori yang tepat tanpa menyalin keseluruhan struktur array. Error handling yang diterapkan adalah pengecekan keberadaan ID (membatalkan operasi jika ID tidak ditemukan) dan memvalidasi agar ID baru tidak bernilai kurang dari 0.

Menu keempat "Hapus Chart" digunakan untuk mereset atau menghapus data chart yang dipilih berdasarkan nilai ID. Program memanfaatkan fungsi `getIndex()` untuk menemukan letak chart di dalam memori. Keterkaitan **pointer** pada menu ini terlihat ketika program langsung menargetkan alamat memori `(C + index)` hasil pencarian tersebut, lalu mengembalikan nilai variabel di dalamnya ke kondisi default/kosong (seperti mengubah nilai ID kembali menjadi -1). Error handling yang diterapkan adalah membatalkan proses penghapusan jika fungsi `getIndex()` mengindikasikan bahwa ID yang dicari tidak ada dalam memori (mengembalikan nilai -1).

Menu kelima "Cari Chart" berfungsi untuk mencari data chart spesifik berdasarkan nilai ID dan menampilkannya. Alur logika pencariannya serupa dengan menu keempat, yaitu menggunakan bantuan fungsi `getIndex()`. Pada menu ini, aritmatika **pointer** digunakan untuk merujuk tepat ke alamat `(C + index)` dari ID yang ditemukan, dan kemudian mendereferensikannya untuk mencetak informasi `idChart`, `nameChart`, dan `difficultyChart` ke layar. Serupa dengan menu sebelumnya, error handling yang diterapkan adalah membatalkan proses pencarian dan menampilkan pesan error jika ID target tidak ditemukan di dalam memori.

Menu keenam "[TUGAS] rata-rata tingkat kesulitan" bertugas untuk mengkalkulasi nilai rata-rata (mean) dari seluruh tingkat kesulitan chart yang tercatat. Fitur ini bergantung pada iterasi aritmatika **pointer** `(C + i)` untuk menelusuri, membaca, dan mengevaluasi isi variabel `difficultyChart` dari setiap elemen `Chart` dalam memori. Nilai tersebut kemudian diakumulasikan dan dibagi dengan jumlah chart yang valid. Error handling yang diterapkan pada fitur ini adalah fungsi validasi `isEmpty()`, di mana kalkulasi akan langsung dibatalkan jika array belum memiliki data sama sekali.

Selain itu, terdapat fitur bonus pencarian nilai min/max yang secara otomatis melacak chart dengan tingkat kesulitan terendah dan tertinggi, yang selalu ditampilkan pada saat program merender menu utama. Sama seperti sebelumnya, fitur ini memanfaatkan iterasi **pointer** `(C + i)` untuk menelusuri memori dan membandingkan variabel `difficultyChart` dari satu elemen ke elemen lainnya guna menentukan nilai yang paling ekstrem. Error handling yang diterapkan juga memanfaatkan fungsi validasi `isEmpty()`, sehingga jika array kosong, program tidak akan mencoba melakukan pencarian dan perbandingan data.

Menu ke-nol "Keluar" digunakan untuk keluar dari perulangan utama program. Bagian ini sangat erat kaitannya dengan penggunaan **pointer** dan memori dinamis. Sebelum program benar-benar berhenti secara keseluruhan, fungsi `free(chart)` dipanggil untuk mendealokasikan (melepas kembali ke sistem) blok memori yang sebelumnya ditunjuk oleh pointer `chart`. Proses pelepasan memori melalui pointer ini krusial untuk mencegah terjadinya kebocoran memori (*memory leak*).

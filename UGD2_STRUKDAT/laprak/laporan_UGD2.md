Program ini adalah sebuah simulasi Mesin Sortir Pabrik berbasis Command Line Interface (CLI) menggunakan bahasa C. Program ini dirancang untuk mensimulasikan proses penumpukan kotak dan penyortiran berdasarkan nomor seri kotak (genap dan ganjil). Dalam pengembangannya, program menerapkan konsep Stack Array, yaitu sebuah struktur tumpukan (Stack) yang dibangun di atas dasar struktur array. Struktur data ini didefinisikan melalui `struct` bernama `Stack` untuk merepresentasikan 3 buah tumpukan penyimpanan (mesin utama, jalur genap, dan jalur ganjil). Dengan konsep stack ini, kotak-kotak dikelola menggunakan prinsip LIFO (Last In, First Out), di mana setiap penyimpanan menyimpan penanda posisi indeks teratas (`top`, `topGenap`, dan `topGanjil`) dan sebuah array berukuran statis (`items`, `genap`, dan `ganjil` berkapasitas 50) yang menampung nomor-nomor seri kotak secara berurutan.

Menu pertama "Tumpuk Kotak" berfungsi untuk memasukkan kotak baru ke dalam mesin utama. Dalam mengeksekusi penambahan kotak, program menerapkan operasi dasar Stack Array, yaitu `push`. Program akan meminta input pengguna, menaikkan nilai `top` mesin utama, lalu menyimpan nilai nomor seri kotak pada indeks array yang baru tersebut. Terdapat error handling pada proses penumpukan ini, yaitu validasi kapasitas stack: sebelum melakukan `push`, program akan memverifikasi apakah mesin penumpuk sudah penuh menggunakan fungsi `isFull()`. Jika dipaksakan menambah saat kapasitas penuh, akan muncul peringatan "[!] Mesin Penumpuk Sudah Penuh [!]".

Menu kedua "Mulai Inspeksi" merupakan fitur untuk menyortir (mengambil) kotak-kotak yang ada di mesin utama dan memindahkannya ke jalurnya masing-masing. Program memindahkan kotak dengan mengecek apakah nomor serinya bernilai genap atau ganjil. Kotak genap akan dimasukkan ke jalur genap melalui operasi `pushGenap()`, sedangkan kotak ganjil dimasukkan ke jalur ganjil melalui operasi `pushGanjil()`. Setelah dipindahkan, tumpukan di mesin utama akan dikosongkan dengan mengembalikan nilai `top` menjadi -1 (mirip dengan implementasi clear/pop secara massal). Error handling yang diterapkan pada proses ini adalah validasi mesin utama kosong: memverifikasi apakah ada kotak untuk diinspeksi menggunakan fungsi `isEmpty()`. Jika terdeteksi kosong, sistem akan memberikan pesan "[!] Tidak Ada Kotak di Mesin Utama Untuk Diinspeksi [!]".

Menu ketiga "Cek Hasil sortir" digunakan untuk menampilkan isi dari gudang tumpukan kotak genap dan gudang kotak ganjil secara visual dari atas ke bawah. Pembacaan dilakukan menggunakan prinsip traversal LIFO, di mana program mencetak data mulai dari indeks teratas (`topGenap` atau `topGanjil`) menurun hingga ke indeks dasar (0). Pada menu ini juga terdapat pengecekan: jika jalur terdeteksi kosong melalui fungsi `isEmptyGenap()` atau `isEmptyGanjil()`, maka program akan sekadar menampilkan "(Kosong)".

Menu keempat "kirim Paket" berfungsi untuk menyimulasikan proses pengiriman dari gudang genap dan ganjil. Program melakukan operasi pengambilan (pop) secara berturut-turut dengan membaca data kotak dari atas tumpukan, lalu mengurangi nilai `topGenap` dan `topGanjil` secara decrement hingga seluruh kotak di kedua gudang habis terkirim (indeks kembali ke -1).

Terakhir, menu 0 (Exit) digunakan untuk mematikan mesin pabrik dan keluar dari program. Ketika dipilih, program akan mencetak pesan "[~] Mematikan Mesin Pabrik [~]" beserta identitas mahasiswa (I Dewa Putu Adhitya Wiraguna - 250713478 - C) sebelum loop utama program akhirnya berhenti berjalan.

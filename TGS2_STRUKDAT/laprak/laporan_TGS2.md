Program ini adalah sebuah simulasi permainan Tower of Hanoi berbasis Command Line Interface (CLI) menggunakan bahasa C. Program ini dirancang untuk memfasilitasi pengguna bermain teka-teki logika memindahkan susunan piringan antar menara dengan aturan tertentu. Dalam pengembangannya, program menerapkan konsep Stack Array, yaitu sebuah struktur tumpukan (Stack) yang dibangun di atas dasar struktur array. Struktur data ini didefinisikan melalui `struct` bernama `Hanoi` untuk merepresentasikan 3 buah menara (a, b, dan c). Dengan konsep stack ini, piringan dikelola menggunakan prinsip LIFO (Last In, First Out), di mana setiap menara menyimpan penanda posisi indeks teratas (`top`) dan sebuah array `items` berukuran statis yang menampung piringan-piringan secara berurutan.

Menu pertama "Tower hanoi" berfungsi untuk memulai permainan dengan mereset ulang jumlah langkah dan menginisialisasi posisi piringan. Dalam mengeksekusi perpindahan piringan antar menara, program menerapkan operasi dasar Stack Array, yaitu `push` dan `pop`. Ketika pengguna memasukkan menara asal dan menara tujuan, program akan "mengambil" piringan dari menara asal melalui operasi `pop()`, yang bekerja dengan cara mengambil elemen array pada indeks `top` lalu menurunkan nilai `top` tersebut. Piringan yang diambil kemudian "diletakkan" ke menara tujuan melalui operasi `push()`, di mana program menaikkan nilai `top` menara tujuan lalu menyimpan nilai piringan pada indeks array yang baru tersebut. Terdapat juga opsi 'd' untuk keluar dari mode permainan. Berikut adalah error handling yang diterapkan pada proses pemindahan ini:
1. Validasi Input Menara: Memastikan input untuk menara asal dan tujuan hanya berupa huruf 'a', 'b', 'c', atau 'd'. Jika input tidak sesuai, sistem akan menampilkan pesan "[!] TIDAK VALID [!]" dan terus meminta input berulang kali hingga benar.
2. Validasi Asal dan Tujuan Identik: Program mengecek jika pengguna memilih menara asal yang sama dengan menara tujuan. Jika demikian, aksi pemindahan dibatalkan dengan menampilkan peringatan "[!] TIDAK VALID [!]".
3. Validasi Menara Asal Kosong: Memverifikasi apakah menara asal memiliki piringan (tidak kosong) sebelum dipindahkan menggunakan fungsi isEmpty(). Jika menara asal terdeteksi kosong, sistem akan memberikan pesan "[!] Tower <nama_tower> Kosong[!]" dan membatalkan langkah tersebut.
4. Validasi Aturan Tower of Hanoi: Memastikan piringan yang ukurannya lebih besar tidak diletakkan di atas piringan yang lebih kecil. Program membandingkan nilai piringan teratas pada menara asal dan tujuan. Jika melanggar, maka program akan menampilkan pesan "[!] TIDAK VALID [!]" dan proses pemindahan akan digagalkan.
5. Validasi Kapasitas Stack (Push/Pop): Pada fungsi dasar `push()` dan `pop()`, diterapkan pengecekan tambahan. Jika dipaksakan push saat penuh, akan muncul peringatan "[!] MENARA FULL [!]". Jika dipaksakan pop saat kosong, akan muncul peringatan "[!] MENARA KOSONG [!]".

Menu kedua "Tampilkan Jumlah Langkah" merupakan fitur untuk menampilkan total perpindahan piringan sah yang sudah berhasil dilakukan pemain. Setiap terjadi fungsi pemindahan piringan (push dan pop yang berhasil) di menu 1, nilai langkah bertambah 1. Fitur ini berguna untuk melacak seberapa efisien langkah yang dihabiskan pemain. Pada menu ini tidak terdapat error handling khusus karena fungsinya murni untuk membaca dan menampilkan nilai variabel bertipe integer.

Menu ketiga "Exit" digunakan untuk keluar dari program secara keseluruhan. Ketika dipilih, program akan mencetak pesan penutup serta identitas (nama, NRP, kelas) sebelum loop utama program akhirnya dihentikan. Menu ini tidak memerlukan error handling khusus.

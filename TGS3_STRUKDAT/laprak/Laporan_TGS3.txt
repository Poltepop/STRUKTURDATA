Program ini adalah sebuah simulasi sistem manajemen pesanan untuk restoran cepat saji (Restoran Cepat Saji Atma) berbasis Command Line Interface (CLI) menggunakan bahasa C. Program ini dirancang untuk memfasilitasi pengguna dalam menerima pesanan masuk dan mendistribusikannya ke dapur yang tepat berdasarkan nomor pesanan (ganjil atau genap). Dalam pengembangannya, program menerapkan konsep Circular Queue Array, yaitu struktur antrean melingkar yang dibangun di atas dasar struktur array berukuran statis. Struktur data ini didefinisikan melalui `struct` bernama `Queue` untuk merepresentasikan antrean pesanan masuk dan antrean dapur (A dan B). Dengan konsep queue ini, pesanan dikelola menggunakan prinsip FIFO (First In, First Out), di mana setiap antrean menyimpan penanda posisi elemen terdepan (`head`), posisi elemen paling belakang (`tail`), dan sebuah array `items` yang menampung nomor pesanan. Sifat melingkarnya (circular) memungkinkan pemanfaatan kembali ruang kosong di awal array ketika `tail` sudah mencapai batas akhir maksimal, selama jumlah antrean belum penuh.

Menu pertama "Terima Pesanan" berfungsi untuk menerima pesanan baru dan memasukkannya ke dalam antrean pesanan masuk. Dalam mengeksekusi penambahan pesanan, program menerapkan operasi dasar Queue, yaitu `enqueue`. Ketika pengguna memasukkan nomor order, program akan mengecek dan meletakkan nilai tersebut pada indeks `tail` yang baru. Jika `tail` sudah mencapai indeks maksimum (MAX - 1) namun masih terdapat ruang kosong di awal array (yaitu saat `head` bergeser), `tail` akan dikembalikan ke indeks 0 untuk mengisi ruang kosong tersebut. Berikut adalah error handling yang diterapkan pada proses ini:
1. Validasi Kapasitas Antrean Masuk (IsFull): Memastikan antrean pesanan masuk belum mencapai batas maksimal (5 pesanan) menggunakan fungsi `isFull()`. Jika pengguna mencoba menambah pesanan saat queue sedang penuh, program akan menampilkan peringatan "[-] Antrian Pesanan Masuk Sudah Penuh (MAX 5) [-]" dan "[!] Queue Is Full [!]", lalu membatalkan proses penambahan pesanan.

Menu kedua "Mulai Proses Pesanan" merupakan fitur untuk memproses seluruh pesanan yang ada di antrean masuk dan mendistribusikannya ke dapur-dapur terkait. Menu ini merepresentasikan perpaduan dari iterasi queue dan proses `enqueue` ke queue lain. Program menelusuri elemen-elemen berurutan secara sirkular dari posisi `head` hingga `tail` pada antrean pesanan masuk. Setiap nomor pesanan dievaluasi; jika bernilai genap, pesanan akan di-push (dengan fungsi `enqueue`) ke Queue Dapur A, sedangkan jika bernilai ganjil akan dimasukkan ke Queue Dapur B. Setelah seluruh pesanan terdistribusi dengan sukses, antrean pesanan masuk yang asalnya berisi pesanan-pesanan tersebut akan dikosongkan (di-reset ulang ke kondisi kosong) melalui pemanggilan fungsi `init()`. Berikut error handling yang diterapkan:
1. Validasi Antrean Kosong (IsEmpty): Mengecek apakah terdapat setidaknya satu pesanan di antrean masuk sebelum dieksekusi menggunakan fungsi `isEmpty()`. Jika terdeteksi kosong, sistem akan memberikan pesan "[!] Antrian Pesanan Masuk Kosong, Tidak Ada Pesanan Yang Di Proses [!]" dan membatalkan aksi pemrosesan karena tidak ada elemen queue yang bisa dioperasikan.

Menu ketiga "Cek Status Dapur" digunakan untuk menampilkan daftar nomor pesanan yang sedang antre (belum diproses lebih lanjut) di Dapur A (Genap) dan Dapur B (Ganjil). Program melakukan proses iterasi (traversal) pembacaan elemen mulai dari indeks `head` hingga ke `tail` pada Circular Queue dari masing-masing dapur. Traversal ini memperhitungkan kondisi saat data melingkar melewati batas akhir array. Error handling yang diterapkan pada menu ini adalah:
1. Validasi Dapur Kosong: Program memverifikasi keberadaan elemen pesanan di setiap queue dapur menggunakan fungsi `isEmpty()`. Jika queue suatu dapur dalam kondisi kosong, program akan menginformasikannya dengan pesan "[!] Dapur <A/B> Masih Kosong [!]".

Menu keempat "[Bonus Statistik Pesanan]" berfungsi menampilkan ringkasan data statistik dari seluruh instance antrean (Queue Masuk, Queue Dapur A, dan Queue Dapur B). Menu ini secara logik menghitung jumlah total elemen yang saat ini menempati antrean dengan memperhitungkan rentang selisih antara `head` dan `tail` pada setiap struktur Circular Queue melalui fungsi pembantu `countQueue()`. Data disajikan ke layar untuk memantau beban atau jumlah node pada tiap-tiap queue. Tidak ada error handling khusus pada menu ini karena sifatnya hanya menghitung kalkulasi panjang queue dan menampilkannya.

Menu ke-nol "Exit" digunakan untuk keluar dari program secara keseluruhan. Ketika dipilih, program akan memutus siklus perulangan utama (do-while) dan mencetak pesan penutup berupa nama, NRP, dan kelas sebelum program akhirnya dihentikan. Menu ini tidak memerlukan error handling khusus.

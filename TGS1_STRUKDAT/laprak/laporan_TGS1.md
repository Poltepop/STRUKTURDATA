Aplikasi ini adalah sebuah Sistem Manajemen Reservasi Meja Restoran berbasis Command Line Interface (CLI) menggunakan bahasa C. Aplikasi ini dirancang untuk memudahkan pihak restoran dalam mengelola pemesanan meja, mendata informasi pelanggan, serta mencatat pesanan makanan dan minuman. Struktur data utama yang digunakan adalah array 2 dimensi (matriks) bertipe `struct` untuk merepresentasikan tata letak meja restoran beserta detail informasi pada setiap mejanya.

Menu "Pesan Meja Resto" berfungsi untuk melakukan reservasi meja baru dengan meminta input baris dan kolom. Pengguna kemudian memasukkan nama pemesan, jenis acara, dan ID reservasi. Terakhir, terdapat opsi untuk memesan makanan. Berikut adalah error handling yang diterapkan pada menu ini:
1. Validasi Baris dan Kolom: Menolak input indeks baris atau kolom yang bernilai negatif atau melebihi batas ukuran array dengan mengulang prompt input terus menerus.
2. Validasi Ketersediaan Meja: Mengecek apakah meja tersebut sudah terisi; jika ya, proses akan dihentikan dan menampilkan pesan error "[!] MEJA SUDAH TERISI [!]".
3. Validasi ID Reservasi: Memastikan ID reservasi tepat terdiri dari 4 karakter; jika tidak, sistem akan memberikan pesan "[!] INVALID [!]" dan mengulang prompt.
4. Validasi Pemesanan Makanan: Saat ada prompt opsi makanan, jika input bukan 'y' atau 'n', akan memunculkan peringatan. Jika 'y', sistem memastikan makanan yang diinput harus sesuai dengan daftar menu (steak, pasta, salad, atau jus) dan akan mengulang jika salah.

Menu "Print All Reservasi" merupakan fitur untuk menampilkan denah keseluruhan meja restoran secara ringkas dalam bentuk matriks. Menu ini akan mencetak kode meja beserta jenis acara dari setiap meja yang ada. Jika meja tersebut belum direservasi, maka status jenis acara akan ditampilkan sebagai tanda hubung ("-"). Fitur ini sangat berguna bagi staf untuk melihat ketersediaan meja secara cepat tanpa memeriksa satu per satu. Pada menu ini tidak terdapat error handling khusus karena fungsinya hanya membaca dan menampilkan seluruh data dari array struktur yang sudah diinisialisasi.

Menu "Print Khusus" digunakan untuk melihat detail informasi reservasi pada satu meja secara spesifik. Pengguna diminta untuk memasukkan lokasi baris dan kolom meja yang ingin dicek. Apabila meja memiliki reservasi, program akan mencetak seluruh data pemesan mulai dari nomor meja, nama, ID reservasi, jenis acara, hingga daftar makanan dan minuman yang dipesan dalam bentuk matriks 2x2. Berikut adalah error handling yang diterapkan pada menu ini:
1. Validasi Meja Kosong: Program memverifikasi apakah meja yang dipilih masih kosong dengan mengecek atribut ID reservasinya. Jika kosong, program akan menampilkan pesan "[!] MEJA MASIH KOSONG [!]" dan membatalkan aksi pemanggilan detail secara otomatis.

Menu "Update Reservasi" memberikan fasilitas untuk mengubah data reservasi meja yang sudah ada. Sama seperti menu sebelumnya, sistem akan meminta input baris dan kolom meja. Proses pembaruan data melibatkan penginputan ulang nama, jenis acara, dan ID reservasi, serta diberikan opsi baru untuk memesan ulang makanan. Berikut adalah error handling yang diterapkan pada menu ini:
1. Validasi Meja Kosong: Mengecek apakah meja tersebut belum memiliki reservasi. Jika kosong, akan muncul pesan error "[!] MEJA MASIH KOSONG [!]" dan proses dibatalkan.
2. Validasi Konfirmasi: Saat program meminta konfirmasi 'y/n' untuk melanjutkan pengubahan data, input selain 'y' atau 'n' akan menghasilkan pesan "[!] INVALID [!]".
3. Validasi ID Reservasi: Seperti pada menu pembuatan reservasi, ID reservasi yang baru harus divalidasi ketat tepat 4 karakter (jika tidak valid, akan terus diminta).
4. Validasi Pemesanan Makanan: Menggunakan aturan validasi yang sama untuk menu restoran, yaitu menolak pesanan makanan yang tidak terdaftar dengan me-looping input hingga benar.

Menu "Batalkan Reservasi" adalah fitur yang memungkinkan pengguna untuk membatalkan pesanan meja yang aktif sehingga meja dapat digunakan oleh pelanggan lain. Setelah menginput baris dan kolom, sistem akan menampilkan rincian data reservasi saat ini agar pengguna bisa memastikan kembali meja yang ingin dibatalkan sebelum direset menjadi kosong ("-"). Berikut adalah error handling yang diterapkan pada menu ini:
1. Validasi Meja Kosong: Memastikan bahwa meja tersebut memang sedang direservasi. Jika ternyata meja sudah kosong (atributnya "-"), maka akan muncul peringatan "[!] MEJA MASIH KOSONG [!]".
2. Validasi Konfirmasi Pembatalan: Setelah menampilkan detail, program meminta konfirmasi 'y/n' terakhir. Jika dijawab dengan input yang tidak valid (bukan 'y' atau 'n'), maka akan muncul peringatan error "[!] INVALID [!]" dan pembatalan akan digagalkan.
